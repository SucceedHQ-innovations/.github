## Engineering Standards

Every repository in this organization follows these non-negotiable practices:

| Standard | Implementation |
|----------|---------------|
| **CI/CD** | GitHub Actions — lint, type-check, test on every push |
| **Documentation** | README (problem → solution → setup), CHANGELOG, API docs |
| **Licensing** | MIT license on all public projects |
| **Security** | `.env` never committed, secrets purged from history, dependency audits |
| **Code Quality** | Issue templates, PR templates, contributing guidelines |
| **Versioning** | Semantic versioning with annotated release tags |
